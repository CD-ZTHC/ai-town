## 摘要

新增效果原语 `goTo`：让目标立刻动身前往某个公开地点，并在那里停留一段时间。

## 动机

世界架构师在尝试实现「萤火节傍晚，把镇上的人都召集到码头一起放灯」时，发现现有能力清单里没有「让居民立刻动身前往指定地点」，只能放弃。这个缺口已出现 1 次。

## 设计

通过扩展点实现，不修改内核：在 `server/ext/go-to.js` 中调用 `registerEffect('goTo', …)`。

- **怎么「动身」**：复用日程机制。`apply` 用 `town.insertEntry` 给每个目标插入一段从下一分钟开始的即时日程（`src: 'commit'`），原有日程在这段时间里被让开，结束后照常继续。居民会像赴约一样自己走过去，所以寻路、到达、到达后的规则触发（`enter`）都沿用现有逻辑。
- **目标**：复用内核导出的 `resolveTargets` / `checkTarget`，支持 `self / target / e / nearby / all`（`nearby` 带 `radius`）。
- **不打扰的情况**：睡着的人、正在交谈或参加群戏的人、异界角色不受影响；22:00 之后不再让人出门。
- **只能去公开地点**：避免把人送进别人家里。

## 参数格式

```
{"op":"goTo","location":"地点id（必须是公开地点）","activity":"≤14字（可选）","minutes":30~180（默认 60）,"target":"self/target/e/nearby/all","radius":1~6}
```

## 使用示例

一个「召集铃」能力：何月在广场摇铃，身边的人一起去码头放灯。

```json
{"op":"addAbility","args":{"id":"gather_bell","name":"召集铃","emoji":"🔔","target":"area","desc":"摇响铃铛，招呼身边的人一起去码头",
 "aiHint":"节日傍晚或需要大家聚在一起时","cost":{"stamina":5},"cooldown":180,
 "effects":[{"op":"goTo","location":"pier","activity":"一起去码头放灯","minutes":90,"target":"nearby","radius":4},
            {"op":"vfx","preset":"notes","color":"#ffd76a","radius":3}]}}
```

也可以写成规则，例如「每天 19:30 萤火节期间，户外的人都去码头」。

## 测试要点

- `check` 拒绝不存在或不公开的地点、越界的 `minutes`、过长的 `activity`、非法 `target`
- `apply` 给附近的人插入即时日程，他们会走到目标地点；睡着和正在交谈的人不受影响；22:00 以后不生效
- 能力清单与架构师提示词里出现 `goTo`（标注为扩展）
- 架构师用 `goTo` 组合出的新能力可以通过校验、落地，并被居民使用（见 `test/evolve.test.js`）

## 风险与安全

- 滥用会让居民频繁被「召唤」：由能力的冷却时间与规则的触发频率上限约束，且每次最多 180 分钟
- 只修改日程，不瞬移、不改变地图，不涉及内容分级

## 备选方案

- 瞬移（直接改坐标）：实现更简单，但居民会凭空消失，观感差，也会绕过寻路与到达事件
- 让导演用多人场景（scene）召集：只能召集指定的 2~6 人，且要走约定流程，不适合「大家一起去」
