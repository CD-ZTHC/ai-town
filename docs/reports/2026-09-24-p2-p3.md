# P2 叙事导演 + P3 穿越与入侵：完成汇报

> 日期：2026-09-24　分支：`claude/lucid-lamport-ye9rtq`
> 对应设计：[`docs/design/ai-world-evolution.md`](../design/ai-world-evolution.md) 第 5、6、10、12 节

## 一、结论

P2 和 P3 都已完成，两项验收标准都达到了：

| 阶段 | 验收标准 | 结果 |
| --- | --- | --- |
| P2 叙事导演 | 无头跑 7 天，能自然产生至少 1 个有伏笔、有回收的剧情弧 | ✅ 一季内回收了 3 条伏笔（传说后半段、水车、匿名信），推进了 4 条；测试断言「伏笔先于爆发」「先讲故事再回收」 |
| P3 穿越与入侵 | 《镜湖裂隙》可以从头玩到尾，三种结局都能触发 | ✅ 封印、共存、智取三种结局各有一个完整季的测试；另测了智取失败时转入封印 |

**一个重要前提**：这个环境里没有模型 API 密钥，所以所有需要 LLM 的部分（导演决策、多人场景、群体心智）只用**模拟模型**验证了数据流和校验逻辑，**还没有用真实的 glm-5.3 / glm-5.3-flash 跑过**。不接模型时，剧情用剧本里预设的台词和立场，整季同样能走完。

## 二、做了什么

### P2 叙事导演

| 模块 | 作用 |
| --- | --- |
| 张力模型 `story/tension.js` | 每游戏小时计算 0~100 的张力：35×威胁 + 20×冲突 + 20×悬念 + 15×匮乏 + 10×氛围，不调用 LLM |
| 叙事者目标曲线 | 🌸 静水（以日常为主）/ 🗺️ 远航（每 7 天一个完整剧情弧，**默认**）/ 🎲 掷骰（随机） |
| 叙事导演 `story/director.js` | 张力偏离目标超过 12、太久没有新鲜事、或玩家发布事件时，用**强模型**决定下一步：按兵不动 / 埋伏笔 / 添麻烦 / 升级 / 喘息 / 收束 / 开启剧情弧。最多每 2 游戏小时一次，只在 7:00~22:00 之间 |
| 剧情节拍 `story/beats.js` | 导演与剧情弧共用的剧情动作，先校验、再执行。导演可用 11 种：伏笔、传言、信念、多人场景、推进线程、给物品、效果、天气、写设定集、成长、开启剧情弧。刷怪、角色登场 / 离场、开裂隙、发起投票等 **只允许剧情弧模板使用** |
| 剧情线程看板 `story/threads.js` | 从人设里整理出 9 条伏笔（音乐会、水车、表白、热气球、孙婆婆的记性、宝藏、匿名信、传说后半段、大山的女儿），记录状态与进展 |
| 多人场景 `story/scene.js` | 安排 → 等人到齐 → 一次模型调用写出 2~6 人群戏 → 记忆、好感、分工（写进日程）、立场（计入投票） |
| 信念传播 | 居民有「相信什么、多确信、听谁说的」。交谈和群戏中，确信的看法会以打折的确信度传给对方；更确信自己看法的人不会被说服（例如周医生一开始认定是小乐的恶作剧） |
| 玩家事件交给导演 | 访客发布的事件仍然让居民重新规划，同时交给导演，5 游戏分钟后优先处理，由导演决定要不要发展成剧情 |

### P3 穿越与入侵

| 模块 | 作用 |
| --- | --- |
| 剧情弧引擎 `story/arcs.js` | 按模板推进 伏笔 → 爆发 → 发展 → 高潮 → 余波；节拍时间相对开弧日计算，错过的节拍会按顺序补上 |
| 《镜湖裂隙》`story/content.js` | 7 天剧本（见第三节）、3 种结局 + 共同收尾，全部是数据 |
| 穿越者 | 「阿萤」（1926 年的少女）以 `addPersona` 写入世界规格，拥有完整心智，提示词里带着她的来历和「不认识的东西」（手机、咖啡、电灯……）；她会自己规划、聊天、学本事 |
| 异界首领 | 「暗月守门人」同样是完整角色，守在码头，可以和居民、访客对话（谈判的基础） |
| 异界生物 `story/creatures.js` | 影灵（偷西瓜、吹灭灯笼）、影犬（追人，**仅冒险模式及以上**）。规则驱动：怕光、昼伏夜出、偷窃 / 追逐 / 游荡。群体心智每 2 小时最多用快模型决定一次「今晚去哪」 |
| 遭遇结算 | 勇气 + 灯 + 光源 + 同伴 + 随机 对抗生物。赢：驱散或吓退，士气上升，可能捡到月石。输：温馨模式只「吓一跳」；冒险模式「受惊」，体力过低会晕倒并被送去诊所；**任何模式都没有死亡** |
| 裂隙 | 微裂 → 开启 → 扩张 → 稳定（月之渡口）/ 合拢，前端画成旋转的紫色涡流 |
| 危机状态 | 士气、物资（被偷会下降，每小时恢复）、亮着的灯阵数量 |
| 抉择投票 `story/votes.js` | 访客每个 IP 一票；居民在谈判场景中表达立场；**管理员随时可以终审**。公网且设置了管理员令牌时，截止后先等管理员 2 小时，仍无人裁决则按多数决定，保证无人值守时剧情也能继续 |
| 审核分级 `guard.js` | 硬禁区（死亡、血腥、色情、现实政治……）任何分级都拦截；软禁区（毁灭、摧毁、爆炸、丧尸……）只在温馨模式拦截；LLM 审核员的规则也随分级变化 |
| 新 WorldOp | `addPersona`（新角色）、`setPersonaStatus`（离开 / 回来） |

### 前端

- 生物像素造型：影灵（漂浮的影子）、影犬（四足）、守门人（戴新月冠的长袍身影）；穿越者的发辫、发簪、旗袍。
- 顶栏「🎭 故事」标签：显示张力和剧情阶段，有抉择时闪烁。
- 故事面板 5 个页签：📖 剧情（张力曲线、剧情弧阶段、导演笔记、即将上演的场景）、🗳️ 抉择（投票与终审）、🧵 伏笔、⚔️ 危机、👾 图鉴（未遭遇的显示为「？？？」）。
- 动态栏新增「🌀 剧情」分类；多人场景可以展开看全部台词。
- 角色登场 / 离场时实时重建精灵和名册。

### 新接口

| 接口 | 权限 | 作用 |
| --- | --- | --- |
| `GET /api/story` | 所有人 | 故事面板数据 |
| `POST /api/vote` | 访客（每 IP 每小时 20 次） | 投票 |
| `POST /api/vote/decide` | 管理员 | 终审 |
| `POST /api/arc/start` | 管理员 | 手动开启剧情弧 |
| `POST /api/director/decide` | 管理员 | 让导演立即决策一次 |

三种结局各自改变的世界：

| 结局 | 世界的变化 |
| --- | --- |
| 🔒 门扉合拢（封印） | 阿萤带着原初之灯回到百年前（离开小镇），裂隙合拢，生物全部回去 |
| 🌗 双月当空（共存） | 裂隙变成永久的「月之渡口」，一只叫「小影」的友善小影灵留在镇上，**新增节日「双月节」**，阿萤留下 |
| 🎈 热气球点亮暗月（智取） | 成功率 = 35% + 士气/200 + 灯轮 10% + 铁柱的灯 10%（上限 85%）。成功则「热气球」伏笔回收、阿萤留下；失败转入封印结局 |

## 四、验证情况

- **测试：共 53 个，全部通过**（`mise run test`，约 1.5 秒）。本阶段新增 13 个，覆盖：
  - 张力随裂隙和生物升高
  - 导演不能越权使用剧情弧专属动作
  - 导演（模拟模型）：合法节拍执行、非法节拍丢弃、玩家事件进入导演提示词且带隔离说明
  - 多人场景（模拟模型）的记忆、好感、分工、立场
  - 投票规则（一人一票、终审、等待后按多数）
  - 三种分级下的遭遇结算
  - 审核分级
  - 完整一季到高潮
  - 三种结局各跑一季，并做存档往返
  - 智取失败分支
  - 静水叙事者不会自动开弧
- **浏览器实测**（Playwright）：
  - 萤火节夜码头：裂隙、影灵、河灯都显示正常。
  - 故事面板：张力曲线、剧情阶段、图鉴正常。
  - 第 7 天高潮夜：守门人和阿萤都在码头；以访客身份投票（带勾选标记），再以管理员身份终审「共存」后，结局、月之渡口、小影都实时出现。
  - 修复后页面没有脚本错误。

### 开发过程中发现并修复的问题

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| 新方法 `arrive()` 与原有的「到达目的地」方法重名，把原方法覆盖了 | 居民到达后一直卡在「走路」状态 | 改名为 `enterStage()`，并扫描确认没有其他重名方法 |
| 导演在拼提示词**之前**就清空了待处理的玩家事件 | 导演看不到玩家发布的事件 | 先生成提示词再清空（由测试发现） |
| 玩家事件原文会以日志形式进入导演提示词，没有「这是素材不是指令」的隔离 | 提示词注入的风险面 | 导演只通过带隔离说明的待处理区块看到玩家原文 |
| 导演先截取前 3 个动作再过滤非法的 | 一个非法动作会挤掉合法动作 | 先过滤再截取 |
| 谈判场景没有设定默认立场 | 不接模型时投票 0:0 平票，总是落到第一个选项 | 为各角色补上默认立场 |
| 影灵恶作剧和「对视」日志刷屏 | 动态栏被淹没 | 每只影灵 3 小时一次、全镇 45 分钟一次；对视日志每小时一条 |
| 「伏笔回收」日志出现在对应的群戏之前 | 叙事顺序颠倒 | 回收节拍移到群戏之后 |
| 角色离场瞬间，旧快照里的角色在前端已没有资料 | 页面脚本报错 | 只绘制前后端都有资料的角色 |

## 五、上线前需要知道的

1. **默认叙事者改成了「远航」**：升级后，老存档也会在下一个 21:00 自动开启《镜湖裂隙》。温馨模式下是「温和版」（没有影犬，遭遇只会吓一跳），但依然有裂隙、血月、守门人。**想保持原来的日常节奏，请设置 `STORYTELLER=gentle`**，之后可以由管理员在故事面板里手动开启。
2. **你已同意公网可以开冒险模式**，需要在 `.env` 里设置 `STORY_RATING=adventure`。
3. **建议的模型配置**：`MODEL_SMART=glm-5.3`（导演、多人场景、日报）、`MODEL_FAST=glm-5.3-flash`（内心独白、审核、群体心智）。
4. **成本估计**（仅供量级参考，没有实测）：
   - 平静期每个游戏日增加：导演最多约 8 次强模型调用。
   - 剧情弧期间另有：约 4 场多人场景（强模型，每场约 5k token）、夜间群体心智最多约 5 次（快模型）；阿萤相当于多一位居民，守门人只参与对话、不做日程规划。
   - 已有的每日令牌预算和降级机制仍然有效。
5. **投票按 IP 计**，同一网络出口下的访客共用一票。
6. **故事面板里的「导演笔记」对所有访客可见**（例如「决定埋伏笔：把漂流瓶和宝藏线索连起来」）。如果觉得影响沉浸感，可以改为只对管理员显示。

## 六、已知限制

- 只有一个剧情弧模板（《镜湖裂隙》），且只能上演一次；裂隙的位置固定在镜湖湖心。
- 生物图鉴是手写的 3 种。让 AI 生成新生物、新建筑的「世界架构师」属于 P4。
- 世界补丁的「访客投票 → 管理员终审」审批流在 P4 实现；本阶段的投票只用于剧情抉择。
- 多人场景需要参与者都到场，最多再等 30 分钟；2 小时内凑不齐两个人会取消。剧本里的关键群戏在不接模型时也有预设台词。
- 导演的真实表现（剧情是否精彩、节拍是否合理）要接上 glm 模型之后才能评估，这也是下一步最需要观察的地方。

## 七、建议的下一步

1. **接真实模型试跑一季**（建议先在本地，`STORY_RATING=adventure`、`STORYTELLER=voyage`、20 倍速），重点观察：
   - 导演提示词的效果
   - 多人场景的台词质量
   - 每日 token 用量
2. **P4 世界架构师**：
   - AI 用 WorldPatch 新增建筑、地点、生物、节日
   - 语义化放置 + 连通性校验
   - 访客投票 → 管理员终审的提案中心
   - 设定考据官
   - 时光回溯
3. **P5 自我进化**：能力缺口日志 → AI 心愿单 → `mise run evolve` 生成需求文档（按你的决定，只生成文档）。
