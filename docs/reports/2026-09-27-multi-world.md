## 各阶段做了什么

**M0**：`server/index.js` 的手写路由迁到 Hono（`server/http/app.js`、`world-api.js`）；一个运行中的世界 = `WorldHost`（Town + 它的 SSE 观众）。

**M1a**：`server/settings/schema.js` 一张声明表覆盖 77 个设置项（zod 类型与范围、分组、说明、`live` / `restart`、启动必需、密钥）；代码里只用 `settings.get`。来源三层：环境变量 > 面板（`data/settings.json`，0600，保留 20 个版本）> 默认值。环境变量写错时拒绝启动并指出是哪一项。守护进程 `server/main.js`：退出码 75 立即重启，新设置连续 2 次启动失败自动回退。管理面板 `/admin`；`mise run settings:doc` 生成 `docs/settings.md`。

**M1b**：`data/accounts.db`（node:sqlite）；scrypt 密码、只存哈希的会话令牌、滑动过期、登出所有设备；`identify / authorize / quota` 三个独立函数；互动必须登录，额度按账号计并有 IP 兜底；写接口校验 Origin；昵称全站唯一（NFKC、去零宽、忽略大小写，冒充词与官方居民名保留，改名 30 天一次、旧名保留 90 天）；居民记忆里存 `{@账号id}`，显示时换成当前昵称；删除了 `x-visitor`。

**M2**：云溪镇的居民、建筑、地点、物品、能力、规则、《镜湖裂隙》、暗月界从代码常量迁到 `worlds/yunxi/`；新增 `voice`（世界名、编年、界面文案）、`rhythm`、`era`、`lore.breakers`；提示词、日报、审核、考据读世界数据；新增 `tragic` 分级。

**M3**：世界登记表与状态机；`WorldManager`（按需加载、上限、休眠卸载、常驻、满员页）；`/`、`/w/:world/`、`/api/w/:world/*`、旧路径映射；三层磁盘上限与回收；首次启动的数据迁移（先备份）。

**M4**：`server/scheduler/`：label → P0~P4 一张表；P0 保留并发、P3+P4 合计 ≤ 1 且只在 P1 为空时、防饿死、让路补偿、别的世界有任务时单世界并发上限；`AsyncLocalStorage` 记账；`usage` 账本与分层预算和降级；按世界调速；进化引擎经 IPC 调用模型（引擎不再联网）。

**M5**：生成器 `layout-v1`（语义布局 → 求解坐标 → 地貌笔刷）；地貌调色板；建筑按参数绘制（屋顶形状、材质、装饰）；WorldOp `addRegion` / `linkRegions`；去掉逻辑里写死的云溪地点；手写的「小红帽」世界包。

**M6**：创世管线 G1~G5（阅读、圣经、改编、生成、验证），组装层把不规整的模型输出变成合法世界包，校验不过带着错误重做一次，子进程无头试跑；原文流式上传与筛查；授予与配额；预览编辑、重新生成、发布前改短名；配角（`tier: support`）；导演的「原著引力」（忠实度、命运节点、偏离度）。

**M7**：发布时自动审核（结构 → 分级 → 关键词 + 模型抽样 → 试跑）；owner 暂停 / 恢复 / 归档 / 设置；举报与自动不公开；管理员下架 / 恢复（在线观众立即看到原因）；运行时抽样审核；owner 终审决策（管理员可否决、撤销）。

**M8**：一台引擎服务所有开启进化的世界，轮转、每世界最多 1 个任务、预算按世界；插件与登记按世界隔离在 `data/worlds/<id>/`，引擎的写权限只给这些目录；旧目录迁移；管理面板「进化」页。

## 发现并修掉的问题

- **共享响应头被写入 `content-length`（`2871560`）**：`@hono/node-server` 的轻量 Response 会往传入的 headers 对象里写长度。404 页直接传了共享的 `SECURITY_HEADERS`，于是一次 favicon 404 之后，所有 API 响应都带着 `Content-Length: 9`，浏览器只读到 `{"total":`。单元测试（`app.request()`）测不出来，是无头浏览器冒烟检查抓到的。改为冻结共享对象、只传拷贝，补了走真实端口的回归测试。
- **世界页面里的登录请求走错了路径（`957b66d`）**：世界页面在 `/w/<世界>/` 下，相对路径 `api/auth/...` 落到了世界接口上（404）。改为 `../../api/auth/`，并在冒烟检查里加了公网模式的端到端流程防止再犯。
- **快照回溯的旧正则**（M0 顺手修）：快照早已改为 `.json.gz`，回溯接口却只认 `.json`。

## 与设计的差异、没有做的部分

以下需要你判断是否接受，或者之后再做：

1. **「偏离即分支」（§4.2）没有实现**：重大偏离不会自动分出时间线。导演提示词里有偏离度与命运节点，导演可以用 `fate` 节拍标记节点到达 / 变形 / 跳过。
2. **创世的简化**：G1 只做「块摘要 → 全书」，没有「段 → 章」的中间层；圣经记录了每个人物在场的块（`witnesses`），但运行时**没有**按 witnesses 检索原文，知识边界只体现在生成初始记忆的提示词里；用户世界**不生成剧情弧**（原著情节以命运节点 + 线程的形式交给导演）；G5 的指标只有卡住率、考据冲突、审核拒绝数，没有「对话重复率」（试跑不调用模型）。
3. **生物的部件组合（§3.1 `bodyPlans`）没有做**：用户世界的反派（例如大灰狼）以普通居民的形式出现。
4. **官方世界多了一个「小红帽」**：M5 验收要求的手写世界包放在 `worlds/little-red/`，因此它会作为第二个官方世界出现在大厅（分级为冒险）。不想公开的话删掉这个目录即可，测试用的是同一份包（需要一起调整）。
5. **测试连接（§14.7）**：保存模型相关设置前会真实调用一次，失败时弹出确认，**仍允许强制保存**，而不是严格禁止。
6. **世界级设置的界面**：owner 在「我的世界」里只能开关进化；叙事者可以通过 `PATCH /api/worlds/:id/settings` 改，分级与 Mod 只有管理员能通过接口改，都还没有界面。
7. **跨世界复用插件为 Mod（§9「后续」）**：按设计留到以后。
8. **仍然保留的全局性**：`timelines`（分支时间线）按世界目录存放，但时间线登记表格式没变；进化引擎的「发现需求」对官方世界仍会用 `EVOLVE_IDEAS` 的点子。
9. **人机验证**：接的是 Cloudflare Turnstile（需要同时配置 `CAPTCHA_SECRET` 与 `CAPTCHA_SITEKEY`），没有做别家。

## 部署与升级提示

- 入口改为守护进程：`node server/main.js`（`mise run start`、Dockerfile、systemd 模板、部署脚本都已更新）。
- 现在有运行时依赖（`hono`、`@hono/node-server`、`zod`），需要 `npm ci`；Node ≥ 22.13（`node:sqlite`）。
- 首次启动自动迁移：`data/` 下的存档 → `data/worlds/yunxi/`；`plugins/evolved/` 与进化登记 → `data/worlds/yunxi/`。都先备份到 `data/backup-*`。旧的 `/api/*` 继续指向云溪镇。
- 公网部署后：注册一个账号 → 打开 `/admin` → 用 `ADMIN_TOKEN` 认领为超级管理员。
- 默认额度有变化：聊天 30 → **45** 句/小时、事件 3 → **4** 个/小时（改为按账号计，另有 IP 兜底）。
- 环境变量现在会被校验，写错会拒绝启动（本机当前的 `.env` 已检查，没有问题）。
