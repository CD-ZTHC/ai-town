# 演出与打击感

> 状态：S1～S5 已实施（2026-10-03，分支 `feat/presentation`，见第 7 节）。
> 目标：三件事——**打击感与音效**、**旅人像素形象**、**演出系统**（Boss 演出、创世过场只是它的内置模板）。
> 关键要求：演出不能写死在某段剧情里，**任何 AI（剧情导演、世界架构师、AI 插件）和任何数据（能力、规则、威胁、负担值、剧情弧）都能调用**。

## 1. 现状

| 方面 | 现在 | 问题 |
|---|---|---|
| 打击 | 飘字、火花、震屏 | 角色本身没有反应（不闪、不退、不顿），出手的人也不动 |
| 声音 | 程序生成的环境音（雨、风、虫鸣） | 战斗没有声音 |
| 旅人 | 几何图形画的小人 | 和像素风的居民放在一起很突兀；没有行走动画 |
| 高光时刻 | 横幅、全屏揭开文字 | 镜头不动、没有节奏；只能由写死的代码触发 |

## 2. 打击感与音效（纯前端）

### 2.1 受击与出手
| 效果 | 触发 | 表现 |
|---|---|---|
| 受击闪白 | 每次命中 | 角色精灵叠一层白光（约 0.12 秒） |
| 受击后退 | 每次命中 | 沿攻击方向位移 0.15～0.35 格再弹回（暴击更远） |
| 出手前冲 | 招式生效 | 出手的人朝目标前冲 0.25 格再收回 |
| 打击停顿 | 暴击、重击、自己挨打、Boss 换阶段 | 画面里的角色停住 60～90 毫秒（只停显示，不影响服务器） |
| 倒地 | 被打倒 | 闪烁两下 |

位移只作用在显示位置上（快照插值之后叠加偏移），对居民、旅人、威胁、生物统一生效。

### 2.2 音效
在现有的 WebAudio 环境音模块里加短音效（全部程序生成，不引入素材文件）：

| 音效 | 用在 |
|---|---|
| `swing` 挥动 | 招式生效（落空也有） |
| `hit` / `crit` 命中 / 暴击 | 命中 |
| `dodge` 闪避 | 闪避 |
| `shield` 护盾 | 护盾吸收 |
| `roar` 低吼 | Boss 登场、换阶段 |
| `quake` 地鸣、`split` 裂开、`chime` 揭开 | 地震、创世、新地方出现 |

- 按与镜头中心的距离衰减，只播放当前看着的地图里的声音；同一帧同类音效合并，避免一拍里几十个命中叠在一起。
- 跟随现有的声音开关（🔇）。

## 3. 旅人像素形象

- 复用居民的像素精灵生成器（`sprites.js` 的 `buildSprites(look)`），旅人有 `look`：衣服颜色（现有 8 色）、发型（短发 / 长发 / 盘发 / 刺头 / 乱发 / 麻花辫）、发色、肤色。
- 角色卡里挑选，预览用同一个生成器画；上次的选择记在浏览器里。
- 服务器只接受白名单里的值（防止乱塞颜色字符串）；旧客户端只传颜色时自动补默认的发型、发色、肤色。
- 行走动画、朝向和居民一致；保留脚下的金色圈（自己）与名牌。受击闪白、后退、前冲同样适用。

## 4. 演出系统

### 4.1 概念

一段**演出（stage）**是一张有上限的「分镜表」：按顺序执行的若干步，每一步是一种镜头或画面元素。演出**只影响观众的画面**，不改变世界状态，不进存档，因此可以放心交给 AI 调用。

```json
{ "op": "stage", "priority": "major",
  "steps": [
    { "do": "letterbox", "on": true },
    { "do": "focus", "target": "threat", "zoom": 1.8, "ms": 900 },
    { "do": "card", "name": "混沌本源", "title": "一切尚未分开之处", "emoji": "🌑", "ms": 1800 },
    { "do": "narrate", "text": "混沌深处的搏动猛地加快。", "ai": "用一句古朴的话描述混沌本源现身", "ms": 2200 },
    { "do": "letterbox", "on": false }
  ] }
```

### 4.2 分镜步骤

| 步骤 | 参数 | 表现 |
|---|---|---|
| `focus` | `target`、`zoom` 0.5~3、`ms` | 镜头平移 / 缩放到目标，结束后跟着目标走 |
| `letterbox` | `on` | 上下黑边（电影感） |
| `slow` | `scale` 0.2~1、`ms` | 画面特效与动画放慢（不影响服务器） |
| `card` | `name`、`title`、`emoji`、`color`、`ms` | 名字卡（人物、Boss 登场） |
| `banner` | `text`、`color`、`ms` | 横幅（已有） |
| `narrate` | `text`、`ai`（可选）、`ms` | 旁白字幕；写了 `ai` 时由模型按提示现写一句，失败用 `text` |
| `flash` | `color` | 全屏闪光 |
| `shake` | `power` 1~12 | 震屏 |
| `vfx` | `preset`、`target`、`color`、`radius` | 特效（已有的预设） |
| `reveal` | `text` | 全屏揭开（已有） |
| `sound` | `sfx` | 音效 |
| `wait` | `ms` | 停顿 |

- **目标**（`target`）：`self` / `target`（效果上下文里的人）、`threat`（威胁上下文里的威胁）、`at`（效果发生的位置）、`loc:地点id`、`agent:居民id`、`region:区域id`（整张地图）。服务器在发出演出时把目标解析成「单位引用 + 当前坐标」，前端跟随单位实时移动。
- **上限**：最多 12 步、总时长 15 秒、文字 ≤ 40 字；超出的部分在校验时拒绝（数据）或截断（AI 现场生成的旁白）。

### 4.3 模板

AI 写完整分镜容易出错，所以提供几个**带参数的模板**，AI 可以只写 `{"op":"stage","template":"…"}`：

| 模板 | 用途 | 参数 |
|---|---|---|
| `intro` | 人物 / Boss 登场 | `target`、`name`、`title` |
| `moment` | 高光时刻（慢镜 + 横幅） | `target`、`text` |
| `reveal` | 新地方出现 | `region`、`text` |
| `aftermath` | 余波（镜头扫过、旁白） | `target`、`text` / `ai` |
| `genesis` | 创世（黑边、慢镜、金光、旁白） | `target`、`text` |

模板展开成普通分镜，之后的流程完全一样；写了 `steps` 时以 `steps` 为准。

### 4.4 谁能调用

| 调用方 | 方式 |
|---|---|
| 世界包数据 | 效果 `stage`：能力、规则、威胁的阶段 / 被打死、负担值到头、剧情弧都能用 |
| 世界架构师（AI） | 写进它提出的规则、能力里（效果清单自动出现在它的提示词里） |
| 剧情导演（AI） | 新的节拍种类 `stage`（导演提示词里有写法） |
| AI 插件 | 经规则 / 能力的效果调用 |
| 世界创建者 / 管理员 | `POST /api/stage`（预览、手动放一段演出） |
| 引擎自动 | Boss 登场、换阶段、被打死，创世能力，新地图出现（见 4.5） |

### 4.5 自动演出（可被数据覆盖）
| 时机 | 默认模板 | 覆盖方式 |
|---|---|---|
| Boss（威胁有 `phases` 或 `boss: true`）第一次开打 | `intro` | 威胁的 `stage.intro` |
| Boss 换阶段 | 横幅 + 震屏 + 低吼 | 阶段里的 `effects` 加 `stage` |
| Boss 被打死 | `moment` | 威胁的 `stage.slain` |
| 创世级能力生效 | `genesis` | 能力的 `stage` |
| 新地图出现（`worldOp`） | `reveal` | —— |

### 4.6 节流与观众的选择
- **服务器**：普通演出（`minor`）全世界至少间隔 30 秒，AI 发得再多也不会刷屏；重大演出（`major`，Boss、创世）不受限，但排队、不叠放。
- **前端**：
  - 演出排队播放，`Esc` / 点「跳过」可跳过；
  - 设置里可以选「演出：全部 / 仅重大 / 关闭」（记在浏览器里）；
  - 游戏模式里，玩家正在战斗时只播字幕类（横幅、旁白、名字卡），不抢镜头；玩家一动方向键就交还镜头；
  - 目标在别的地图上：重大演出临时切过去、结束后切回；普通演出只播字幕。

### 4.7 Boss 血条
威胁有 `phases` 或 `boss: true` 时，开打后屏幕顶部显示大血条（名字、当前阶段），和演出独立。

## 6. 风险
- **抢镜头惹人烦**：节流 + 观众设置 + 游戏模式下不抢镜头 + 随时跳过。
- **AI 写坏分镜**：严格校验与上限；模板降低出错率；旁白由服务器调用模型并截断。
- **性能**：打击停顿与慢镜只改前端的显示时间；音效合并；演出不进快照。

和方案的出入：
- 旁白不再「等模型写好再发」——实测会让登场演出晚到十几秒（Boss 已经掉了四成血）。改为演出立即发出，模型写好的旁白作为补发的字幕（`follow`）叠上去；模型失败时有 `text` 就用 `text`，没有就不放。
- 「倒地闪烁」只做了旅人（被打倒后半透明闪烁）；居民倒地沿用原来的流程。
