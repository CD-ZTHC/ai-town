# 即时战斗与创世能力

> 状态：C0～C5 已实施（分支 `feat/realtime-combat`，见第 9、10 节）。
> 决策（2026-10-03 确认）：
> 1. 战斗做成**动作游戏**的手感：玩家能直接操控角色出招（第一步是游戏模式里的旅人化身）。
> 2. 创世不需要审批：它创造的是**世界内的区域**，不是一个新世界。
> 3. 「身化万物」用 `transform`（离开世界并触发效果），不算死亡，任何分级都能玩。
> 4. 先做 C0～C2：即时战斗内核、技能进战斗、前端表现与操控。

## 1. 现状

| 已有 | 现在的情况 | 不够的地方 |
|---|---|---|
| 属性 | `hp/stamina/courage`，人设 `combat.atk/def`，装备 `mods/tags` | 没有速度、抗性等战斗维度 |
| 战斗 | 人对人每**游戏分钟**一回合普攻对砍；人对威胁 `hunt` 一次性结算 | 不是即时的，技能进不了战斗，前端只有一行日志 |
| 技能 | 数据化能力，由效果原语组合，有消耗、冷却、条件 | 只能改「人和东西」，碰不到世界结构 |
| 区域 | `addRegion / addAdjacentRegion / linkRegions / expandMap` 等世界操作，可重放、会重建地图 | 只有 AI 建筑师和管理员能调 |
| 表现 | 6 种特效、气泡、日志 | 没有血条、飘字、读条、打击感 |

## 2. 原则

- 内核只加通用能力：「盘古、混沌、开天」等名词只出现在世界包数据里。
- 战斗的每一拍都不调模型，按规则结算（可重放、成本可控）；模型只在开战、关键时刻、事后介入（C3）。
- 存档兼容：没有 `combat` 字段的技能、没有敌人的世界照旧。
- 分级与权限：人打人仍过 `mayHarm`；玩家对居民动手只有世界所有者 / 管理员可以，而且只会打倒、不会杀死；对会死的威胁、敌对的异界生物，任何人都可以动手。

## 3. 即时战斗内核（C0、C1）

### 3.1 战斗时钟

战斗在主循环里按**真实时间**推进，固定每 0.25 秒一拍（`BEAT`），与游戏时间流速无关（世界暂停、休眠时战斗也停）。
一场战斗在现实里打十几秒到一分钟；最长 `MAX_BEATS`，到时各自散开。

### 3.2 战斗单位

居民、旅人化身、会死的威胁、异界生物统一成一个「战斗单位」（`UnitRef = {kind, id}`），由适配器读写位置、血量、属性：

| 属性 | 来源 |
|---|---|
| `hp / maxHp` | 居民 `body.hp`（上限 100 + 装备 `mods.hp`）；化身内存里的血量；威胁 `inst.hp / def.hp`；生物 `hp / stats.hp` |
| `atk / def` | 现有 `computeStats`（人设 + 勇气 + 装备）；威胁 `def.atk / def.def` |
| `spd` | 人设 `combat.spd`、威胁 `speed`；影响移动与出手节奏 |
| `tags` | 装备标签，攻击威胁时比对弱点 |

### 3.3 一招的节奏

每个战斗单位同一时间只做一件事：**蓄力（windup）→ 生效 → 硬直（recover）**。

- 蓄力期间受到重击（≥ 最大血量的 15%）会被**打断**；被眩晕时当前招式作废。
- 内建两招：`strike` 普攻（所有单位都有）、`dodge` 闪避（短冲刺 + 几拍无敌，化身专用）。
- 能力加上可选的 `combat` 块就能在战斗中使用：

```json
"combat": { "windup": 2, "recover": 3, "range": 3, "shape": "single|circle|line|cone", "radius": 2, "cd": 16 }
```

拍数为单位；居民使用时照常支付体力、物品、负担值的消耗，冷却按战斗拍数另算。

### 3.4 战斗用的效果原语

| 原语 | 作用 |
|---|---|
| `strike` | 对招式命中的敌人造成伤害：`power`（攻击力倍数）+ `add`，带 `tags`，对上弱点 ×1.5 |
| `status` | 挂状态若干拍：`stun` 眩晕、`root` 定身、`shield` 护盾、`haste` 加速、`slow` 减速、`bleed` 流血、`weaken` 虚弱、`guard` 架势 |
| `knockback` | 把命中的敌人击退若干格 |

不在战斗中时：`strike` 对身边会死的威胁生效（同 `damage`），`status / knockback` 无效果。

### 3.5 谁来出招

- **玩家**：游戏模式里的旅人化身，键盘 / 按钮直接出招（见第 4 节）。
- **规则 AI**（其余单位）：每拍给可用的招式打分——距离、冷却、血量、命中人数、招式类型（伤害 / 控制 / 治疗 / 护盾）——选最高的；够不着就走过去；撑不住又不够勇敢就逃跑（沿用旧规则）。

### 3.6 开打与结局

- 开打：居民的 `attack` 行动、`hunt` 会死的威胁、玩家出招、会死的威胁撞上身边的旅人（有攻击力的才会主动动手）。
- 一方已经在战斗里时，新加入的人站到对面一边（多人混战）。
- 结局沿用伤势阶梯：居民被打倒 → 按意图与分级走重伤 / 被俘 / 死亡；威胁被打死 → 掉落、事件结束；生物 → 被驱散；化身 → 倒地后回到出生点、血量恢复。
- 写记忆：开打、被打倒、打倒别人、旁观者亲眼所见。

### 3.7 存档

`fights` 字段改为新结构（`{id, beat, region, fighters[]}`）；旧存档里的回合制打斗读档时直接丢弃（只是进行中的瞬时状态）。含化身的战斗里化身不进存档，读档后视为离场。

## 4. 前端表现与操控（C2）

- **快照**新增 `fights`：每个参战单位的血量、当前招式与读条进度、状态。
- **事件** `combat`：每一拍的出招与命中（伤害、暴击、打断、闪避、击退），前端用来画飘字和特效。
- 画面：
  - 参战单位头顶血条与读条，状态图标；
  - 伤害飘字（暴击放大、治疗绿色）、命中闪白、打断提示；
  - 新特效：`slash` 斩击、`beam` 光束、`projectile` 弹道、`shockwave` 冲击波、`lightning` 雷击、`shield` 护盾泡；
  - 大招（蓄力 ≥ 3 拍）的招式名横幅；重击、暴击、自己挨打时震屏。
- 操控（游戏模式）：
  - `WASD` 走位；`J` 普攻（自动锁定最近的敌人）；`K` 闪避；`1～4` 技能（世界包 `combat.avatarKit` 里的能力）；
  - 屏幕下方的技能栏显示冷却；自己的血条；手机上是按钮。

## 5. 创世能力（C4）

- 效果原语 `worldOp`：能力执行白名单内的世界操作（`addRegion / addAdjacentRegion / linkRegions / expandMap / addBuilding / setWeather / addPersona`），走现有的世界操作入口（可重放、可撤回、自动重建地图）。参数由世界包预写，或 `generate` 交给建筑师生成；**不需要审批**。
- 安全阀：带 `worldOp` 的能力必须标 `power: "genesis"`，只有人设 `tier: "primordial"` 的角色能学会和使用；AI 进化不能授予；有使用次数；区域上限不变。
- 效果原语 `transform`：角色离开世界并触发一组效果（不走死亡流程，不受死亡预算限制）。
- 效果原语 `phase`：Boss 血量到阈值切换阶段。
- 新区域揭开动画：从黑暗中裂开，地块逐格长出。

## 6. 验收世界包《开天》（C5，纯数据）

| 阶段 | 内容 | 机制 |
|---|---|---|
| 开局 | 只有一小块「混沌」，盘古沉睡 | 区域、剧情弧 |
| 醒 | 混沌里滋生浊气兽，盘古持巨斧开打 | 即时战斗、群战、装备标签 |
| 劈开混沌 | Boss「混沌本源」三阶段，击败后放「开天」 | `phase`、蓄力大招、`worldOp: addRegion` |
| 撑天 | 天地每天想合拢（负担值），盘古每天「顶天立地」 | `burden`、`expandMap` |
| 身化万物 | 负担到顶触发 `transform`：山川、江河、日月、草木 | `transform` + 多个 `worldOp` + `addPersona` |
| 之后 | 世界交给后来者，继续自主演化 | 现有小镇系统 |

| 阶段 | 内容 | 验证 |
|---|---|---|
| C0 | 战斗单位、快时钟、旧回合战斗迁移 | 原有战斗相关测试改为驱动战斗时钟后通过 |

## 8. 风险

- 主循环负载：战斗时钟只在有战斗时运转，每个世界同时进行的战斗有上限（`MAX_FIGHTS`）。
- 旧世界兼容：夜巡、小红帽的人打人、`hunt` 迁移后结局规则不变（只是从一下子结算变成打完一场）。
- 操控延迟：出招走 HTTP，服务器按拍结算；前端立即播放本地的出招反馈，结果以服务器为准。

和设计的出入：

- 化身对居民动手只有 `subdue`（打倒送诊所），不会杀死、抓走。

## 10. C3～C5 与「AI 创造战斗技能」实施记录（2026-10-03）

### AI 创造战斗技能
- `addAbility` 保留 `combat` 块（校验沿用 `checkCombatBlock`），架构师的写法说明里有例子；`power` 字段被拒绝（创世级能力只能写在世界包里）。
- 新的世界操作 `setAvatarKit {ids}`：整体替换旅人的技能栏，最多 4 个、只能是带 `combat` 块的非创世能力；架构师可以提出。

### C3 战斗里的人心（`server/sim/combat-mind.ts`）
- 居民加入战斗时定战术：`aggressive / defensive / protect / flee`。先用兜底规则（`fallbackTactic`）立即生效，模型（标签「战斗战术」）的回复到了再覆盖，并说一句开场白。
- 居民血量第一次低于 30% 时说一句话，模型可以改战术（标签「战斗台词」）。没有模型、出错时用 `fallbackLine`。
- 战术影响选招（猛攻偏伤害、稳守 / 护人偏护身）、逃跑阈值、目标（护人时打正在打自己人的那个敌人）。
- 旁观者（6 格内）：对某一方好感 ≥ 50 且勇气 ≥ 45 的冲上去帮忙，战术为护人；胆小的只记下「没敢上前」。对居民出手要世界允许敌对，不会对旅人出手。

### C4 创世原语
| 内容 | 说明 |
|---|---|
| 能力 `power: "genesis"`、`uses` | `worldOp / transform`（以及 `cast` 创世级能力）只能出现在创世级能力里；只有人设 `tier: "primordial"` 的角色能拥有（世界包校验、学习、寄宿授予、使用时都检查）；次数记在世界标记里 |
| 效果 `worldOp` | 白名单内的世界操作，地形参数由系统求解（同架构师提案），走 `applyWorldOp`（记入历史、可重放）；失败时记一条「力量落了空」 |
| 效果 `transform` | 这个人离开世界（`departed`，不算死亡），其他人记住；之后的效果照常执行 |
| 效果 `cast` | 让某人立即使用一项能力（规则、剧情里用） |
| 威胁 `skills / phases / onSlain / aggro` | 威胁会用带 combat 块的能力；Boss 按血量比例进入阶段（喊话、横幅、换招、攻击倍数、阶段效果）；被打死时执行效果；`aggro` 主动扑向身边的居民 |
| AI 的边界 | AI 写的规则（`addRule`）、能力（`addAbility`）、旅人技能栏都碰不到创世效果 |
| 前端 | 特效 `split`（金色裂缝 + 震屏）、`quake`；Boss 阶段红色横幅；地图长出新区域时的全屏揭开动画 |
| 新地貌 | `chaos` 混沌、`sky` 天穹、`mountain` 山地 |

和设计的出入：`phase` 没有做成效果原语，而是威胁数据里的 `phases`（更直接）；`generate` 不经过建筑师的提案流程，而是单独调用一次模型（见第 11 节）。

### C5 《开天》（`worlds/pangu/`，纯数据）
- 开局：混沌一张地图，盘古（primordial）、两头浊气兽（`aggro`）；浊气兽每两小时在盘古身边凝成。
- 14:00 后混沌本源找上门：两次阶段变化（换招、护盾、攻击 ×1.5），打死后 `onSlain` 立起标记 `chaos_split`。
- 规则让盘古 `cast` 开天：长出「天穹」（北）与「大地」（南）两张相邻地图；剩下的浊气兽按 `resolve` 对抗沉进大地。
- 每 6 小时撑天：天穹向北扩展一丈（`expandMap`），天地之重 +25；第四次到顶触发 `onFull`：`transform` + 山川、江河两张地图、日月天气、两位初民（禾、石生）、写进设定集。
- 测试 `test/pangu.test.ts` 跑完整个故事（含重启重放一致、初民在新地图上生活），并检查权限边界。

顺带修复：家在其他地图上的居民（区域里的角色、新地图上化生的人）睡觉时会因为只在主地图上找家而出错，出生时的区域也固定写成了主地图（`sim.ts` 的 `createAgent`、`sim/movement.ts` 的 `settle`）。

## 11. 收尾（2026-10-03）

| 问题 | 处理 |
|---|---|
| 《开天》部署后会直接出现在大厅 | 世界包新字段 `listed: false`：第一次登记为「不公开」（不进大厅，链接可以进）；管理员在后台「世界」页把状态切成「公开」即可上架，之后重启不会改回去。《开天》默认不公开 |
| 天穹一层层长高时，每层之间有一条横路和一排树丛 | 没有地点的扩展块标记为 `bare`：不修沿接缝的横路，只有一条从中间穿过的路，原地图边缘的树丛清掉；旧存档里的扩展块没有这个标记，画法不变 |
| 新天气权重最多 20，开天后一半时间还是混沌 | 新世界操作 `setWeatherWeights`（只在创世能力的 `worldOp` 白名单里，架构师不能提出）；新效果 `weather`（天气立刻变成某种）。《开天》一开始就写好权重为 0 的「日月」，化身时把混沌调成 0、日月调成常见并立刻放晴。开局天气改为「会出现的天气里权重最大的」（以前有 sunny 就用 sunny） |
| 区域布局只能由世界包预写 | `worldOp` 新参数 `generate`（意图）：模型现场设计名字、地貌与地点（标签「创世布局」），位置参数（id、from、side、length……）仍由世界包定；不合法的地点直接丢弃，放不下时逐步收缩（两块 → 合成一块 → 更少地点），都不行才用世界包写的兜底布局。《开天》的山川、江河用了它 |
| 战斗战术只用模拟模型测过 | 用本机配置的真实模型跑过：萧九对沈砚动手，萧九「猛攻」并说「陆承的狗，也配拦我？」，沈砚「稳守」，濒死台词正常返回；JSON 全部可解析。创世布局第一次跑时模型把地点写空了（提示词里写了「同上」），改为写全结构后正常生成（例如「盘古首岳」：发丝林、云雾井、盘古顶、绕云径） |
| 有模型时故事引擎又放出了混沌本源 | 混沌本源加上 `resolve` 对抗：天地分开后每小时检查，聚不起来就散掉 |
